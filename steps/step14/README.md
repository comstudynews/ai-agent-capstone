# Recipe 14. Dynamic Planning

**학습 순서:** 무엇을 배우는가 → 왜 필요한가 → 작은 실행 → 코드 읽기 → 결과 확인 → 응용

## 1. 무엇을 배우는가?
초기 계획과 실행 결과에 따른 수정 과정을 설명합니다.

## 2. 시작 전 확인
- 이전 Recipe를 실행했고 프로젝트 폴더 `ai-agent-capstone/`에 있는지 확인합니다.
- 외부 계정이 없어도 기본 예제를 실행할 수 있습니다.
- 문제가 생기면 [공통 문제 해결 가이드](../../docs/TROUBLESHOOTING.md)를 참고합니다.

## 3. 가장 작은 예제부터 실행

```bash
uv run python -m app.lesson 14
```

**예상되는 출력의 핵심 키:** `plan`. 출력 내용을 보고 이 단계에서 무엇을 배웠는지 한 문장으로 설명해 보세요.

같은 예제의 실행 파일을 별도로 확인하려면 다음 명령을 사용합니다.

```bash
uv run python -m steps.step14.complete
```

**주의:** 기본 예제는 범위가 제한된 결정적 Planning입니다.

## 4. 코드 읽기

[`app/core.py`](../../app/core.py) 파일을 열고 입력값, 반환값, 변경되는 상태가 무엇인지 찾아봅니다. 화면에 나온 결과와 소스코드의 함수가 어떻게 연결되어 있는지 확인하세요.

## 5. 응용 연습

장애 상태를 바꾸었을 때 계획 항목이 달라지는지 비교하세요.
