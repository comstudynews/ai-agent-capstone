# Recipe 10. 오류 처리

## 1. 무엇을 배우는가?
정상 조회 결과 없음과 서비스 장애를 구별합니다.

## 2. 시작 전 확인
- 이전 Recipe를 실행했고 프로젝트 폴더 `ai-agent-capstone/`에 있는지 확인합니다.
- 외부 계정이 없어도 기본 예제를 실행할 수 있습니다.
- 문제가 생기면 [공통 문제 해결 가이드](../../docs/TROUBLESHOOTING.md)를 참고합니다.

## 3. 가장 작은 예제부터 실행

```bash
uv run python -m app.lesson 10
```

**예상되는 출력의 핵심 키:** `missing_status`. 출력 내용을 보고 이 단계에서 무엇을 배웠는지 한 문장으로 설명해 보세요.

같은 예제의 실행 파일을 별도로 확인하려면 다음 명령을 사용합니다.

```bash
uv run python -m steps.step10.complete
```

**주의:** 장애 처리 전략을 검토하는 기본 실습입니다.

## 4. 코드 읽기

[`app/api.py`](../../app/api.py) 파일을 열고 입력값, 반환값, 변경되는 상태가 무엇인지 찾아봅니다. 화면에 나온 결과와 소스코드의 함수가 어떻게 연결되어 있는지 확인하세요.

## 5. 응용 연습

없는 서비스 이름으로 질의하여 NOT_FOUND가 표시되는지 확인하세요.

## 6. 오류 해결·완료 확인

- [ ] 명령을 프로젝트 폴더에서 실행했습니다.
- [ ] 예제 출력에서 `missing_status` 항목을 찾았습니다.
- [ ] 해당 함수를 읽고 입력과 출력을 설명할 수 있습니다.
- [ ] 예제 값을 바꾼 뒤 다시 실행했습니다.
